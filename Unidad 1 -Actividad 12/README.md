# Unidad 1 - Actividad 12

## Descripción general
En esta actividad se realizó la configuración de un servidor de correo electrónico en Linux. Para ello se utilizaron herramientas como Postfix y Dovecot, con el fin de permitir el envío y la recepción de correos dentro de una red local.

## Objetivo
Comprender de manera práctica cómo funciona un servidor de correo y cómo se relacionan protocolos como SMTP, POP3 e IMAP en la comunicación entre cliente y servidor.

## Resultado
Al finalizar la práctica, se logró establecer la comunicación entre el servidor y el cliente de correo, comprobando que el servicio funcionaba correctamente y de forma segura.
